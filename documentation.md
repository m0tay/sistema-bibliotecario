# Documentação do Sistema Bibliotecário de Terminal

**Estrutura de Menus**

O sistema possui vários menus que permitem ao usuário navegar entre diferentes opções e executar ações. Cada menu é acessado digitando um número ou uma tecla para voltar. Abaixo estão os menus disponíveis no sistema e as opções correspondentes.

**Menu Principal**

No menu principal, o usuário pode acessar as seguintes opções:

1.  **Library** - Acessa o menu da biblioteca.

2.  **Backups** - Acessa o menu de backups.

3.  **Settings** - Acessa o menu de configurações.

4.  **Exit** - Sai do sistema.

**Menu Library**

Dentro do menu **Library**, as opções disponíveis são:

1.  **Books** - Gerenciar livros.

2.  **Users** - Gerenciar usuários.

3.  **Lendings** - Gerenciar empréstimos.

4.  **Audit** - Realizar auditoria.

5.  **Go back** - Voltar ao menu anterior (Menu Principal).

**Menu Backups**

Dentro do menu **Backups**, as opções são:

1.  **See path for backup storage** - Ver o caminho de armazenamento dos backups.

2.  **List backups** - Listar todos os backups.

3.  **Create a new backup** - Criar um novo backup.

4.  **Delete a backup** - Excluir um backup.

5.  **Go back** - Voltar ao menu anterior (Menu Principal).

**Menu Settings**

No menu **Settings**, o usuário pode configurar as seguintes opções:

1.  **Width** - Ajustar a largura do display.

2.  **Page size** - Ajustar o tamanho das páginas.

3.  **Go back** - Voltar ao menu anterior (Menu Principal).

**Menu Browse (Users, Books e Lendings)**

No menu **Browse**, as opções para navegar são:

1.  **Previous page** - Voltar para a página anterior.

2.  **Next page** - Avançar para a próxima página.

3.  **Expand** - Expandir a visualização.

4.  **Add** - Adicionar um novo item (livro, usuário, etc.).

5.  **Go back** - Voltar ao menu anterior.

**Menu Model Actions (Users, Books e Lendings)**

Dentro do menu **Model Actions**, as opções são:

1.  **Edit** - Editar o modelo (livro, usuário, etc.).

2.  **Delete** - Excluir o modelo selecionado.

3.  **Go back** - Voltar ao menu anterior.

**Menu Deletion (Users, Books e Lendings)**

No menu **Deletion**, o usuário pode confirmar a exclusão de um item:

1.  **Confirm deletion** - Confirmar a exclusão do item selecionado.

2.  **Go back** - Voltar ao menu anterior.

**Como Usar**

Para usar o sistema, siga as instruções a seguir:

1.  **Selecione uma opção** - Quando um menu for exibido, você verá as opções listadas junto com os números correspondentes. Digite o número da opção desejada e pressione **Enter**.

2.  **Voltar ao menu anterior** - Para voltar ao menu anterior, digite **‘q’** e pressione **Enter**.

3.  **Ações específicas** - Dependendo da opção selecionada, você poderá realizar ações como editar, excluir, listar ou criar itens dentro do sistema.

Este sistema foi desenvolvido para uma navegação simples e intuitiva, facilitando a exploração das funcionalidades de forma eficiente e sem complicação.
